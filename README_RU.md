# KONTRA WEB v2 — Live Players

Рабочая версия сайта KONTRA // ZOMBIE с живым статусом сервера и таблицей игроков.

## Уже работает

- Apple-style night UI;
- язык по умолчанию EN и ручной переключатель EN / RU;
- живая карточка сервера через Cloudflare `/status` и D1;
- статус online/offline, онлайн, заполнение, карта, режим и время обновления;
- компактный список T / CT на главной;
- полная таблица во вкладке «Сервер»;
- ник, команда, жив/мёртв, HP, броня, счёт, смерти и отметка BOT;
- автоматическое обновление каждые 15 секунд;
- кнопка Share передаёт только публичную ссылку без авторизации;
- компактное нижнее меню и выдвижной drawer;
- окно входа по логину и паролю — пока только интерфейс;
- заготовки разделов Control, Top и Profile.

## Пока не подключено

- LVL, убийства LVL MOD, K/D, игровое время, матчи, победы и токены;
- реальная авторизация;
- управление LVL MOD / GAME MENU / Classes / Admin;
- карта по fingerprint и изображения карт;
- пинг игрока — текущий sender это поле пока не передаёт.

Сайт не создаёт ложные значения: отсутствующие данные не имитируются.

## Публикация

Заменить содержимое текущего GitHub Pages-репозитория файлами из этой папки. `config.js` уже содержит действующий endpoint статуса и адрес сервера.
