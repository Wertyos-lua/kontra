# KONTRA WEB v5 — игроки и глобальный ТОП

## Что добавлено

- Любого игрока в коротком списке или полной таблице теперь можно нажать.
- Открывается карточка с живыми данными: команда, статус, HP, броня, счёт и смерти.
- Если у игрока есть синхронизированный аккаунт LVL MOD, карточка дополнительно показывает уровень, убийства, смерти, K/D, время, матчи и победы.
- Раздел «ТОП» подключён к D1 и поддерживает сортировку по уровню, убийствам, победам и игровому времени.
- В рейтинге отображаются роль и текущий онлайн игрока.

## Что обновить

1. В Cloudflare Worker целиком поставить `KONTRA_WORKER_v3_3_PLAYERS_TOP_D1.txt` и нажать Deploy.
2. В GitHub заменить файлы сайта из этого комплекта.
3. Cloudflare Pages автоматически развернёт новую версию.

Bindings, D1, KV, UPDATE_TOKEN и остальные секреты менять не нужно.
