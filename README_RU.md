# KONTRA WEB v4 — Authorization Connected / Cloudflare Pages

Рабочая версия сайта KONTRA // ZOMBIE с живым статусом, таблицей игроков и безопасной авторизацией.

## Уже работает

- Apple-style night UI;
- EN по умолчанию и ручной переключатель EN / RU;
- живая карточка сервера через Cloudflare `/status` и D1;
- компактный список T / CT и полная таблица игроков;
- вход из игры по одноразовой персональной ссылке `/site`;
- ручной вход по игровому логину и паролю;
- сохранение сессии на устройстве и кнопка выхода;
- профиль LVL MOD: ник, роль, уровень, убийства, смерти, K/D, игровое время, матчи, победы, WR и токены;
- роли PLAYER / VIP / ADMIN;
- публичная кнопка Share без передачи персональной ссылки и сессии;
- автоматическое обновление статуса каждые 15 секунд;
- адаптивный интерфейс для телефона.

## Схема авторизации

1. Игровой сервер синхронизирует текущий профиль игрока с Worker через защищённый `/auth/sync`.
2. Команда `/site` создаёт одноразовую ссылку, действующую 2 минуты.
3. После погашения ссылки сайт получает отдельную 30-дневную сессию.
4. Для ручного входа Worker сверяет пароль с PBKDF2-хешем в D1.
5. Пароль, deviceId и серверный UPDATE_TOKEN не возвращаются браузеру.

Ручной вход становится доступен после того, как игрок хотя бы один раз был синхронизирован новым серверным мостом.

## Требуемые серверные компоненты

- `LVL_MOD_v69.lua` или новее;
- `KONTRA_WEB_AUTH_BRIDGE_v1_1.lua`;
- `KONTRA_WORKER_v3_2_AUTH_D1_PAGES.txt` в Cloudflare Worker;
- существующие bindings `STATUS_DB`, `STATUS_KV` и secret `UPDATE_TOKEN`.

## Пока не подключено

- команды управления LVL MOD / Classes / GAME MENU / Admin из сайта;
- глобальный топ игроков;
- карта по fingerprint, `/maps`, `/maps_info` и изображения карт;
- пинг игрока.
