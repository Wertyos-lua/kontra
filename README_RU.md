# KONTRA WEB v1

Первая чистая версия нового сайта KONTRA // ZOMBIE.

## Уже работает

- новый Apple-style night UI;
- язык по умолчанию EN и ручной переключатель EN / RU;
- живая карточка сервера через существующий Cloudflare `/status`;
- статус online/offline, онлайн, заполнение, карта, режим, время обновления;
- кнопка Share передаёт только публичную ссылку без авторизации;
- компактное нижнее меню;
- выдвижное меню;
- окно входа по логину и паролю — пока только интерфейс;
- заготовки разделов Server, Control, Top, Profile.

## Пока не подключено

- список игроков T / CT;
- LVL, убийства, смерти, K/D и профиль;
- реальная авторизация;
- управление LVL MOD / GAME MENU / Classes / Admin;
- карта по fingerprint.

Для этих функций потребуется расширить Worker и Lua-мост. Ложные данные сайт не показывает.

## Публикация

Заменить содержимое текущего GitHub Pages-репозитория файлами из этой папки. `config.js` уже содержит действующий endpoint статуса и адрес сервера.
