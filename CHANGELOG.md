# Changelog

## v4 — Authorization Connected / Cloudflare Pages

- Исправлена ручная авторизация: форма отправляет запрос в Worker `/auth/login`.
- Включён `authEnabled`.
- Подключён `authBaseEndpoint`.
- Публичный URL перенесён на `https://wertyosluakontra.pages.dev/`.
- Убраны старые сообщения-заглушки о неподключённом backend.
- Добавлен cache busting `?v=4` для `styles.css`, `config.js` и `app.js`.

## v3 — Authorization & LVL MOD Profile

- Подключена реальная авторизация через Cloudflare Worker v3.1 и D1.
- Добавлен автоматический вход по одноразовой ссылке, созданной командой `/site` в игре.
- Добавлен ручной вход по игровому логину и паролю.
- Добавлены восстановление 30-дневной сессии, `/auth/me` и выход из аккаунта.
- На главной отображается компактная карточка авторизованного игрока.
- Во вкладке «Профиль» отображаются роль, LVL, убийства, смерти, K/D, игровое время, матчи, победы, WR и токены.
- Добавлены роли PLAYER / VIP / ADMIN с разным оформлением.
- Персональный `ticket` удаляется из адресной строки сразу после погашения.
- Публичная кнопка Share использует только чистый адрес сайта без ticket и сессии.
- Полная локализация авторизации и профиля на EN / RU.

## v2 — Live Players

- Подключён живой список игроков из Cloudflare API v2 / D1.
- На главной добавлен компактный предпросмотр команд T и CT.
- Во вкладке «Сервер» реализована полная таблица игроков.
- Для каждого игрока отображаются ник, команда, жив/мёртв, HP, броня, счёт, смерти и отметка BOT.
- Добавлены корректные состояния: сервер офлайн, сервер пуст, список временно недоступен.
- Данные выводятся безопасно через `textContent`.

## v1

- Новый шаблон с чистого листа.
- EN по умолчанию, EN / RU в шапке.
- Apple-style dark UI.
- Живое подключение к Cloudflare status API.
- Нижняя навигация и компактный drawer.
