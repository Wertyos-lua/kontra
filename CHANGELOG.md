# Changelog

## v2 — Live Players

- Подключён живой список игроков из Cloudflare API v2 / D1.
- На главной добавлен компактный предпросмотр команд T и CT.
- Во вкладке «Сервер» реализована полная таблица игроков.
- Для каждого игрока отображаются: ник, команда, жив/мёртв, HP, броня, счёт, смерти и отметка BOT.
- Добавлены корректные состояния: сервер офлайн, сервер пуст, список временно недоступен.
- Список автоматически обновляется вместе со статусом каждые 15 секунд.
- Полная локализация новых элементов на EN / RU.
- Данные выводятся безопасно через `textContent`; HTML из ников не исполняется.

## v1

- Полностью новый шаблон с чистого листа.
- EN по умолчанию, EN / RU в шапке.
- Apple-style dark UI.
- Живое подключение к существующему Cloudflare status API.
- Публичный Share без передачи сессии.
- Login UI подготовлен без небезопасной имитации авторизации.
- Нижняя навигация и компактный drawer.
- Подготовлены разделы Server, Control, Top, Profile.
